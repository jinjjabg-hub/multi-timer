멀티타이머 개인정보처리방침

시행일: 2026년 10월 12일

멀티타이머(이하 "앱")는 이용자의 개인정보를 최소한으로 다루며, 이름·이메일·전화번호 같은 개인 식별 정보를 요구하거나 수집하지 않습니다. 이 방침은 앱이 어떤 정보를 어디에 저장하는지 설명합니다.

1. 기기 안에만 저장되는 정보

스톱워치, 타이머, 프리셋, 발표 시간 설정, 완료 기록, 소리·진동 설정은 이용자 기기의 브라우저 저장소(localStorage)에만 저장됩니다. 개발자 서버로 전송되지 않으며, 앱 데이터를 지우거나 앱을 삭제하면 함께 삭제됩니다.

2. 발표 모드(방 코드)를 사용할 때

여러 기기를 연결하는 발표 모드를 사용할 때만 Google Firebase 서비스를 이용합니다.

항목내용목적
익명 식별자Firebase 익명 로그인이 만드는 무작위 ID (이름·이메일과 연결되지 않음)방 만든 기기만 타이머를 조작하도록 확인
방 정보6자리 방 코드, 슬롯 이름·시간 설정, 발표자 명단, 타이머 진행 상태운영자·발표자·보조 화면 사이 동기화
  • 방 정보는 마지막 사용 후 24시간이 지나면 자동으로 삭제되도록 설정되어 있습니다.
  • 데이터는 Google Firebase(Firestore, 서울 리전 asia-northeast3)에 저장되며, 전송 구간은 암호화(HTTPS)됩니다.
  • 발표자 명단에 이용자가 직접 입력한 이름은 같은 방 코드로 입장한 사람에게 보입니다. 필요한 최소한의 이름(별칭 권장)만 입력해 주세요.

3. 수집하지 않는 정보

  • 위치, 연락처, 사진, 마이크·카메라 정보
  • 광고 식별자, 광고 및 행동 분석 데이터 (앱에는 광고와 분석 도구가 없습니다)

4. 기기 기능 사용

  • 진동: 타이머 종료 시 알림을 위해 사용합니다.
  • 화면 켜짐 유지: 타이머 실행 중 화면이 꺼지지 않게 하기 위해 사용합니다.

5. 제3자 제공

이용자 정보를 판매하거나 광고 목적으로 제3자에게 제공하지 않습니다. 발표 모드에서 사용하는 Google Firebase는 서비스 제공을 위한 처리자이며, Google의 개인정보처리방침이 함께 적용됩니다.

6. 아동

앱은 연령과 관계없이 사용할 수 있으나, 아동의 개인정보를 별도로 수집하지 않습니다.

7. 이용자의 권리와 삭제 요청

기기 안의 정보는 앱 설정의 "기록 지우기" 또는 앱 데이터 삭제로 직접 지울 수 있습니다. 발표 모드 데이터는 24시간 안에 자동 삭제되며, 그 전에 삭제를 원하면 아래 연락처로 방 코드를 알려 주세요.
