# 멀티타이머
1. `index.html`에서 역할 선택: 혼자 쓰기 / 운영자(새 방 만들기) / 발표자 화면 / 보조 화면.
2. 운영자 폰에서 "새 방 만들기" → 6자리 방 코드 → 태블릿·PC에서 같은 코드로 입장.
3. 운영자는 "다음 사람 시작"만 누름 (자동 진행 없음). ⚙ 설정에서 명단·시간·벨소리 변경.
4. 방은 마지막 사용 후 24시간 뒤 자동 삭제: Firebase 콘솔 → Firestore → TTL → 컬렉션 그룹 `rooms`, 필드 `expireAt` 추가.
5. 규칙은 `firestore.rules`를 콘솔 → Firestore → 규칙에 붙여넣고 게시.
